# 🚀 Профессии в IT: найди своё будущее

Чат-бот ВКонтакте для профориентации школьников. Ученик отвечает на 10 коротких вопросов, а бот с помощью **искусственного интеллекта (GigaChat от Сбера)** подбирает подходящую IT-профессию, рассказывает, в чём она заключается, какие навыки нужны и с чего начать обучение.

Проект сделан для хакатона, кейс **«Профессии в IT: найди своё будущее»**.

## ✨ Возможности бота

| Функция | Как вызвать | Что делает |
|---|---|---|
| Профориентационный тест | «Начать», «Старт» | 10 вопросов с кнопками, в конце — рекомендация профессии |
| Возврат к вопросу | «Назад» | Отменяет последний ответ и возвращает к прошлому вопросу |
| Выход из теста | «Отмена» | Прерывает тест и открывает меню |

| Полезные ресурсы | «Ресурсы» | Бесплатные сайты и курсы для старта |
| Справка | «Помощь» | Что умеет бот |
| Главное меню | «Меню» | Кнопки основных команд |
| Проценты совпадения | в конце теста | Три лучших совпадения с профессиями в процентах |

**Профессии, которые рекомендует бот:**
🌐 Веб-разработчик · 🧪 Тестировщик (QA) · 🎨 UI/UX-дизайнер · 📱 Разработчик мобильных приложений · 🎮 Разработчик игр

Команды можно писать с любым регистром. Ответы на вопросы выбираются кнопками, свободный текст во время теста бот не принимает и просит нажать кнопку.

## 🤖 Как используется ИИ

В проекте ИИ используется для **генерации персональной рекомендации** школьнику.

**Как это работает:**

1. После последнего ответа бот собирает **запрос (промпт)** для нейросети. В него входят: роль («школьный профориентолог в сфере IT»), все 10 вопросов с ответами ученика, предварительный подсчёт баллов по профессиям и требования к формату ответа (профессия, суть, навыки, с чего начать, до 1200 символов).
2. Запрос уходит в **GigaChat** — нейросеть Сбера (бесплатный пакет токенов для физлиц). Используется модель `GigaChat-2` через официальную библиотеку `gigachat`.
3. ИИ выбирает одну профессию из списка и пишет рекомендацию простым языком. Ответ отправляется ученику как есть.

**Что происходит, если ИИ недоступен.** Бот не ломается, у него три уровня:

| Приоритет | Источник рекомендации | Когда включается |
|---|---|---|
| 1 | GigaChat | задан ключ `GIGACHAT_AUTH_KEY` |
| 2 | Любой OpenAI-совместимый API (Groq, OpenRouter и др.) | GigaChat не ответил, заданы `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL` |
| 3 | **Анализ по баллам** — готовые описания профессий из `texts.py` | ИИ не ответил или ключей нет |

Анализ по баллам работает без интернета и без нейросети: каждый ответ даёт баллы профессиям, побеждает набравшая больше всех (подробнее в разделе [«Как считаются баллы»](#-как-считаются-баллы)).

**Важно:** проценты совпадения в конце теста всегда считаются по баллам, а не нейросетью. Предварительный подсчёт передаётся ИИ в запросе, поэтому его рекомендация, как правило, согласуется с процентами, но ИИ может учесть ответы целиком и выбрать иначе.

## 💬 Как проходит диалог

```
Пользователь: Начать
Бот:          Приветствие + «Вопрос 1 из 10» + кнопки с вариантами
Пользователь: (нажимает кнопку)  ← можно нажать «Назад» или «Отмена»
   ...        повторяется 10 раз
Бот:          «В процессе... подбираю профессию»
              → запрос к ИИ (или анализ по баллам)
Бот:          «Это твой результат!»
Бот:          Рекомендация: профессия, суть, навыки, с чего начать
Бот:          📊 Проценты совпадения (топ-3)
Бот:          Предложение пройти тест заново + главное меню
```

## 🧩 Устройство кода

### `it_career_bot.py`

Файл разбит на блоки (в коде они отмечены заголовками `# ===== ... =====`):

**Настройки.** Ключи и параметры читаются из переменных окружения (`os.getenv`), в коде их нет. Это безопаснее: токены не попадут на GitHub.

**Состояния пользователей.** Словарь `user_states`:

```python
user_states = {
    123456789: {"step": 3, "answers": ["Творчество", "Да, обожаю", "Игры"]},
}
```

- ключ — ID пользователя ВК;
- `step` — номер текущего вопроса (0 — первый);
- `answers` — ответы, данные до сих пор.

Если пользователя нет в словаре, значит он не в тесте и ему доступны команды меню. Так бот понимает, на каком вопросе находится каждый человек, даже когда пользователей много.

**Основные функции:**

| Функция | Назначение |
|---|---|
| `main()` | Подключается к ВК, слушает новые сообщения через Long Poll, передаёт их в `handle_message`. При сбое соединения перезапускает прослушивание |
| `handle_message()` | Главный «маршрутизатор»: определяет команду («Начать», «Профессии» и т.д.) или передаёт сообщение тесту |
| `handle_test_message()` | Обрабатывает сообщения во время теста: «Отмена», «Назад», выбор ответа, проверка, что ответ — один из вариантов |
| `ask_question()` | Отправляет текущий вопрос с кнопками и номером «Вопрос N из 10» |
| `finish_test()` | Считает баллы, запрашивает ИИ, отправляет результат, пишет статистику, очищает состояние |
| `compute_scores()` | Подсчёт баллов и процентов по профессиям |
| `scores_text()` | Формирует блок «Твои совпадения» (топ-3) |
| `build_prompt()` | Собирает запрос для нейросети |
| `ask_gigachat()` | Запрос к GigaChat |
| `ask_openai_compatible()` | Запрос к любому OpenAI-совместимому API |
| `ask_ai()` | Пробует ИИ по очереди (GigaChat → OpenAI-совместимый), возвращает `None`, если никто не ответил |
| `menu_keyboard()`, `professions_keyboard()`, `answers_keyboard()` | Клавиатуры ВК |
| `send()` | Отправка сообщения (с клавиатурой или без) |
| `load_stats()`, `record_stat()`, `stats_text()` | Статистика в `stats.json` |

**Обработка сообщений в `handle_message`** идёт в таком порядке:

1. «Начать» / «Старт» — запуск теста (работает всегда, даже посреди теста: начнётся заново);
2. если человек в тесте — сообщение уходит в `handle_test_message`;
3. иначе команды меню: «Помощь», «Меню», «Профессии», название профессии, «Ресурсы», `/stats` (только админам);
4. всё остальное — подсказка нажать «Начать» + меню.

### `texts.py`

| Что внутри | Для чего |
|---|---|

| `MENU_PROMPT`, `HELP`, `CATALOG_INTRO`, `RESOURCES`, `CANCELLED`, `CANT_GO_BACK`, `SCORES_HEADER` | Тексты новых функций |

## 🧮 Как считаются баллы

Формат вопроса в `texts.py`:

```python
{
    "text": "Как ты обычно решаешь задачи?",
    "options": [
        ("По плану, шаг за шагом",       P(T, W)),   # тестировщик, веб-разработчик
        ("Нестандартно, ищу свой путь",  P(G, D)),   # игры, дизайнер
        ("Проверяю каждую мелочь",       P(T, M)),   # тестировщик, мобильный
    ],
},
```

`P(a, b)` означает: выбранный ответ даёт по **1 баллу** профессиям `a` и `b`.

**Нормировка.** В пометках к ответам одни профессии встречаются чаще других. Без поправки «частые» профессии выигрывали бы слишком часто. Поэтому баллы каждой профессии делятся на число её упоминаний во всём тесте, а результат переводится в проценты (сумма = 100%). В пробном прогоне на случайных ответах каждая профессия побеждала в 12–25% случаев.

## ⚙️ Установка и запуск

### 1. Требования
Python 3.9 или новее.

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Токен сообщества ВК
1. Откройте сообщество → «Управление» → «Работа с API».
2. Вкладка «Ключи доступа» → «Создать ключ». Отметьте право «доступ к сообщениям сообщества».
3. Вкладка **Long Poll API**: включите, версия API 5.131 или новее, в типах событий отметьте «Входящее сообщение».
4. «Управление» → «Сообщения»: включите сообщения сообщества.

### 4. Ключ GigaChat (необязательно)
1. Зайдите на [developers.sber.ru/studio](https://developers.sber.ru/studio) через СберID.
2. Создайте проект «GigaChat API» и нажмите «Получить новый ключ».
3. Ключ авторизации показывается **один раз** — сразу сохраните его.

Без ключа бот работает в режиме анализа по баллам.

### 5. Переменные окружения и запуск

**Windows (cmd):**
```cmd
set VK_TOKEN=токен_сообщества
set GIGACHAT_AUTH_KEY=ключ_авторизации
set ADMIN_IDS=123456789
python it_career_bot.py
```

**Linux / macOS:**
```bash
export VK_TOKEN=токен_сообщества
export GIGACHAT_AUTH_KEY=ключ_авторизации
export ADMIN_IDS=123456789
python it_career_bot.py
```

Значения пишутся **без кавычек**, а бот нужно запускать из того же окна терминала. Когда в консоли появится «Бот запущен!», откройте сообщество от своего личного аккаунта (не из режима управления), нажмите «Написать сообщение» и отправьте «Начать».

## 🔧 Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `VK_TOKEN` | да | Токен сообщества ВК |
| `GIGACHAT_AUTH_KEY` | нет | Ключ авторизации GigaChat. Нет ключа — работает анализ по баллам |
| `GIGACHAT_MODEL` | нет | Модель GigaChat, по умолчанию `GigaChat-2` |
| `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL` | нет | Запасной OpenAI-совместимый API (Groq, OpenRouter и т.п.). Нужны все три |
| `ADMIN_IDS` | нет | ID ВК администраторов через запятую. Только им доступна команда `/stats` |

## ✏️ Как изменить тексты и вопросы

Всё содержимое лежит в `texts.py`, код менять не нужно.

- **Изменить сообщение бота** — отредактируйте текст в кавычках (например, `WELCOME`).
- **Изменить вопрос или ответ** — правьте строки в `QUESTIONS`. Текст кнопки не длиннее 40 символов, вариантов от 2 до 4.
- **Добавить вопрос** — добавьте ещё один блок в список `QUESTIONS`. Число вопросов бот определяет сам.
- **Изменить описание профессии** — правьте текст в `PROFESSIONS`.

После правок сохраните файл и перезапустите бота.

## ⚠️ Ограничения

- **Состояния хранятся в памяти.** При перезапуске бота все незавершённые тесты сбрасываются.
- **Бот работает в одном процессе.** Для хакатона и демо этого достаточно, для большой нагрузки нужна доработка.
- **Проверка SSL-сертификата GigaChat отключена** (`verify_ssl_certs=False`): у сервиса сертификат Минцифры, которого нет на многих компьютерах. Для боевого проекта лучше установить сертификат и включить проверку.
- **Бесплатный пакет GigaChat ограничен** по токенам и по условиям тарифа, которые определяет Сбер. Проверяйте их при регистрации.
- **Рекомендация ИИ не заменяет профориентолога.** Бот подсказывает направление для первого знакомства с IT, но не даёт окончательного совета.
